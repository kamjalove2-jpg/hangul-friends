# 한글 친구들 (40개월 아이용 한글 놀이 웹앱)

아이패드 Safari에서 열어 "홈 화면에 추가"하면 앱처럼 쓰는 PWA입니다. 빌드 과정이 없는 정적 파일입니다.

## GitHub Pages 배포
1. GitHub에서 새 저장소 만들기 (예: `hangul-friends`, Public)
2. 이 폴더의 파일 전체를 저장소 루트에 올리기 (GitHub Desktop 또는 웹의 "Upload files")
3. 저장소 Settings → Pages → Branch: `main` / `/ (root)` → Save
4. 1~2분 뒤 `https://<아이디>.github.io/hangul-friends/` 접속
5. 아이패드 Safari에서 열고 공유 버튼 → "홈 화면에 추가"

## 파일을 고친 뒤
`sw.js`의 `VERSION` 값을 올려야 아이패드 캐시가 갱신됩니다.

## 구성
- 따라쓰기(자음 14·모음 10) + 캐릭터 스티커 / 풍선 터뜨리기 / 글자 블록 / 그리기 / 스티커북·꾸미기 / 내 이름 쓰기
- 그리기: 자유 그리기 / 그림 따라 그리기(14종) / 사진·내 캐릭터 위에 그리기(사진 또는 선 그림) / 🪣 색 채우기 · ↩️ 되돌리기
- 부모 모드(홈의 ⚙️, 덧셈 확인): 사용시간 제한, 난이도 4단계, 소리 크기, AI 목소리 선택, 읽어주기 방식(AI 다음 내 녹음), 이름, 진행도, 내 목소리 녹음, 내 캐릭터(사진 추가·백업), 초기화

## 내 캐릭터 사진
부모 모드에서 추가한 사진은 그 iPad의 브라우저 저장소(IndexedDB)에만 저장되고 이 저장소(GitHub)에는 올라가지 않습니다.
저작권이 있는 캐릭터 이미지는 이 저장소에 커밋하지 마세요.
캐릭터 이름의 첫 글자로 자음·모음을 연결하면(로디 → ㄹ) 그 글자의 그림·단어가 캐릭터로 바뀝니다(대체/추가 선택).

## 다른 기기로 옮기기
부모 모드 → "백업 · 다른 기기로 옮기기"에서 💾 전체 백업 저장(설정·이름·캐릭터·녹음·진행도) → 받는 기기에서 📂 불러오기(합치기/덮어쓰기).
AI 목소리 선택은 기기마다 달라 옮기지 않습니다.
